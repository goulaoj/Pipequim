# Projecto Computacional MQ-II

Projeto de Mecânica Quântica para o estudo de sistemas de duas partículas idênticas,
incluindo estatística bosónica e fermiónica, estados espaciais, spin total e potenciais
como o oscilador harmónico e o poço de potencial infinito.

O código permite calcular:
- Energias dos estados
- Funções de onda
- Densidades de probabilidade
- Valores esperados
- Visualizações 2D e 3D



## Requisitos

### Python
- Python ≥ 3.9

### Bibliotecas
- numpy
- matplotlib

Instalação das dependências:

pip install numpy matplotlib


## Como Executar

No diretório principal do projecto:

python main.py
